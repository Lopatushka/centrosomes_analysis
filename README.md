# Centrosome and Centriole Analysis

A Fiji/ImageJ and Python workflow for manual quantification of **centrosomes and centrioles in fluorescence microscopy images**.

The workflow allows the user to manually identify centrosomal objects in microscopy images, save the selected regions of interest (ROIs), and subsequently analyze the number of detected objects per cell.

The final output reports the **percentage of cells containing a specified number of centrosomes or centrioles**.

---

## Overview

The analysis consists of two main steps:

1. **Microscopy image analysis in Fiji**

   * Open `.czi` microscopy images.
   * Split fluorescence channels.
   * Generate maximum-intensity projections.
   * Display merged images.
   * Manually identify centrosomal/centriole objects.
   * Save ROIs and measurements.

2. **Data analysis in Python**

   * Load measurement CSV files generated by Fiji.
   * Separate measurements by fluorescence channel.
   * Count detected objects per cell.
   * Assign cells to experimental samples.
   * Classify cells according to a user-defined threshold.
   * Calculate the percentage of cells above the threshold.
   * Generate publication-ready bar plots.

### `run.py`

Fiji/ImageJ script used for interactive microscopy image analysis.

The script:

* recursively searches the selected directory for `.czi` files;
* opens each microscopy image;
* splits the image into three channels;
* allows the user to select the Z-slices used for analysis;
* generates maximum-intensity projections;
* creates merged fluorescence images;
* allows manual selection of objects using the Fiji multipoint tool;
* records ROIs separately for each cell and channel;
* saves ROI sets as `.zip` files;
* saves measurements as `.csv` files.

### `utils.py`

Python functions used for downstream data processing and visualization.

Main functions include:

```python
load_data()
data_subset()
processing()
barplot_normal()
```

# 1. Fiji image analysis

## Image requirements

The current Fiji workflow expects **three-channel microscopy images**.

The channels are interpreted in `run.py` as:

```text
Channel 1 → DAPI / nuclei
Channel 2 → measurement channel 1
Channel 3 → measurement channel 2
```

For example, an experiment may contain:

```text
DAPI
γ-tubulin
Pericentrin
```

The script currently processes files with the extension:

```text
.czi
```

---

## Running the Fiji script

Open Fiji and run:

```text
run.py
```

using the Fiji Script Editor with the Python/Jython interpreter.

The program will first ask for:

1. the directory containing microscopy images;
2. the directory where analysis results should be saved.

The input directory is searched recursively for `.czi` files.

---

## Maximum-intensity projection

For each image, the program asks which Z-slices should be included in the maximum-intensity projection.

For example:

```text
First slice: 3
Last slice: 12
```

Maximum-intensity projections are then generated independently for all three channels.

---

## Merged images

Two merged images are generated for manual analysis:

```text
Measurement channel 1 + DAPI
Measurement channel 2 + DAPI
```

The images are displayed side-by-side to facilitate comparison of centrosomal structures between the two markers.

---

## Manual object selection

Objects are identified manually using the Fiji **Multipoint Tool**.

For every cell:

1. Select the centrosomal/centriole objects in the first measurement channel.
2. Confirm the selection.
3. Select the corresponding objects in the second measurement channel.
4. Confirm the selection.
5. Continue with the next cell.

Select **Next image** when all cells in the current image have been analyzed.

---

## Fiji output

For every analyzed image, the script saves a CSV table containing information such as:

```text
Image
Cell
Channel number
ROI
```

Example:

```text
Image_01    1    1    ROI_01
Image_01    1    1    ROI_02
Image_01    1    2    ROI_01
Image_01    1    2    ROI_02
Image_01    1    2    ROI_03
```

Each row corresponds to one manually identified object.

ROI sets are additionally saved as `.zip` files:

```text
<image>_cell_<cell>_ch_<channel>.zip
```

Merged images are also saved in the selected output directory.

# 2. Python analysis

The generated CSV files can be analyzed using `notebook.ipynb`.

## Requirements

The downstream analysis requires Python and the following packages:

```bash
pip install pandas numpy matplotlib scipy jupyter
```

---

## Load the data

Set the directory containing the CSV files:

```python
DIR = "/path/to/results"
```

Then load all CSV files:

```python
from utils import load_data

df = load_data(DIR)
```

`load_data()` recursively searches the directory for CSV files and combines them into a single Pandas DataFrame.

The source filename and path are automatically stored in:

```text
File
Path
```

---

## Select a fluorescence channel

Measurements can be separated by channel:

```python
from utils import data_subset

ch1 = data_subset(df, channel=1)
ch2 = data_subset(df, channel=2)
```

The two channels can therefore be analyzed independently.

---

## Count objects per cell

Each ROI represents one detected object.

The number of objects in every cell can therefore be calculated using:

```python
df_objects = (
    ch2.groupby(["Image", "Cell"])["ROI"]
       .count()
       .reset_index(name="Objects_number")
)
```

The resulting table has the structure:

```text
Image        Cell    Objects_number
Image_01     1       2
Image_01     2       4
Image_01     3       1
```

---

## Assign experimental samples

Each cell should be assigned to its corresponding experimental condition.

For example:

```python
df_objects["Sample"] = "Control"
```

or according to information encoded in the image/file name.

Example conditions might include:

```text
Control
Treatment
WT
Mutant
```

---

## Define the threshold

The main analysis parameter is:

```python
THRESHOLD = 3
```

A threshold of `3` means that cells containing:

```text
≥ 3 objects
```

are classified as positive.

For centrosome analysis, this can therefore be interpreted as:

> Percentage of cells with ≥3 centrosomes.

The threshold can be changed depending on the biological question.

---

## Calculate percentages

Use:

```python
from utils import processing

results = processing(
    df=df_objects,
    threshold=THRESHOLD
)
```

The resulting table contains:

```text
Sample_name
Above_threshold
N_total_cells
Percentage
SD
```

where:

* `Above_threshold` — number of cells meeting or exceeding the threshold;
* `N_total_cells` — total number of analyzed cells;
* `Percentage` — percentage of positive cells;
* `SD` — error value used for visualization.

---

## Plot results

Results can be visualized using:

```python
from utils import barplot_normal

barplot_normal(
    df=results,
    output_dir="./results",
    threshold=3,
    parameter="centrosomes"
)
```

The graph reports:

```text
% Cells with 3 or more centrosomes
```

The figure is saved as a high-resolution PNG (`600 dpi`).

# Example workflow

A typical analysis can be performed as follows:

```python
from utils import load_data, data_subset, processing, barplot_normal

DIR = "./results"
OUTPUT_DIR = "./results"

THRESHOLD = 3
PARAMETER = "centrosomes"

# Load Fiji measurements
df = load_data(DIR)

# Select measurement channel
data = data_subset(df, channel=2)

# Count objects per cell
objects = (
    data.groupby(["Image", "Cell"])["ROI"]
        .count()
        .reset_index(name="Objects_number")
)

# Assign experimental condition
objects["Sample"] = "Sample1"

# Calculate percentage of cells above threshold
results = processing(
    df=objects,
    threshold=THRESHOLD
)

# Plot
barplot_normal(
    df=results,
    output_dir=OUTPUT_DIR,
    threshold=THRESHOLD,
    parameter=PARAMETER
)
```

## Notes

* The Fiji script currently expects images containing exactly **three channels**.
* Object detection is **manual**, allowing the user to visually verify centrosomal structures.

* Channels can be analyzed independently.
* The threshold can be modified according to the experimental question.
